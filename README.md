# Hermes Pocket updates

[Download the latest APK](https://github.com/YoseHel/hermes-pocket-updates/releases/latest).

Install the APK over your existing Hermes Pocket installation. Do not uninstall first: your saved connection and settings are retained.

After installing version 0.9.4 or later, open **Settings → App updates → Update now** inside Hermes Pocket for future updates. If Android asks, allow **Install unknown apps** for Hermes Pocket, return to the app, and confirm installation.

This repository contains only signed APK releases, checksums and the public update feed. Application source is maintained in a separate private repository. No GitHub login is needed on your phone.
